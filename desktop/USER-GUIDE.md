# FileRecall v0.4 使用手册

FileRecall 可以搜索你选定目录中的文件，也能收纳 Chrome 和 Motrix／aria2 的下载记录。找到文件后，点开详情查看当前位置、原路径和已知来源。

## 1. 安装与首次使用

1. 在 [Windows 构建记录](https://github.com/afarii/FileRecall/actions/workflows/desktop.yml?query=branch%3Afeat%2Fdesktop-v0.4-mvp) 里打开最新成功的构建，下载并解压 `FileRecall-Windows-x64`，运行其中的 `FileRecall-Setup-*-x64.exe`。安装包适用于 Windows 10／11 x64，内置运行环境，目前为未签名的验收版。
2. 打开 FileRecall，点「授权目录 → 添加文件夹」。先选一个几份文档所在的目录，等待界面显示「自动监控中」。
3. 回到「搜索文件」，输入文件名的一部分。点中文件后，可在右侧详情打开文件、在资源管理器定位或复制路径。

从 v0.4.0 升级时，右键托盘图标选择「退出 FileRecall」，再用 v0.4.1 安装包覆盖安装。索引和设置保存在当前 Windows 用户的 `%APPDATA%\filerecall-desktop`。

从 v0.4.1 起，Windows 安装版在运行期间会检查预览版更新，缩到托盘时也会检查。也可以从顶部「软件更新」手动检查。看到新版时，依次点「下载新版」和「重启并安装」。客户端只向 GitHub 请求更新信息和安装包。

## 2. 搜文件和正文

| 我记得什么 | 在哪里搜 |
| --- | --- |
| 文件名、路径、下载网站 | 用「字面搜索」。下方可切换「本地文件」「Chrome 下载」「Motrix／aria2」或状态筛选。 |
| 文件里的一句话 | 在「授权目录」开启「搜索文件正文」，等待重新扫描，再输入原句。结果会标明「正文匹配」。 |
| 大意或同义描述 | 开启正文索引后，切到「本地 AI 搜索」，首次点「下载本地模型」，模型约 135 MB。下载完成后输入描述并点「搜索」，之后可断网使用。 |
| 自己写过的标签或备注 | 打开文件详情中的「收藏、备注和标签」，保存后可按文字搜索，也可用「收藏」筛选。 |

正文支持 UTF-8 TXT、Markdown（不超过 128 KiB），以及带文字层的 PDF 和 `.docx`（文件不超过 20 MiB）。PDF 读取前 100 页。扫描件需先有可选中的文字层。

例如在测试目录的 Markdown 写下「第四季度预算」，启用正文索引后，可以先搜原文，再试语义描述「冬天的开销计划」。AI 比较最近索引的最多 500 份文档，每份取最多三段。语义匹配表示内容相近，文件来历仍需单独核对。

客户端运行时，按 `Ctrl+Shift+Space` 可从其他窗口唤出搜索。可在顶部「搜索热键」修改。搜索框里按方向键下移到结果，按回车查看详情。

在 Windows 点窗口右上角的「×」会隐藏到系统托盘，热键、目录监控和 Motrix 同步继续运行。可按热键或点任务栏通知区域的 FileRecall 图标重新打开窗口。图标也可能在「^」的隐藏图标区。要完全退出，请右键图标，选「退出 FileRecall」。

## 3. 同步下载记录

### Chrome 直接下载

1. 首次安装扩展时，在 `chrome://extensions` 打开「开发者模式」，点「加载已解压的扩展程序」，选择含 `manifest.json` 的 FileRecall 目录。已安装用户更新原目录后，点现有扩展的「重新加载」以保留记录。
2. 复制 Chrome 扩展管理页显示的 FileRecall 扩展 ID。打开 Windows 安装版的「Chrome 设置」，粘贴 ID，点「保存连接」。
3. 在 Chrome 点 FileRecall 扩展图标，打开「下载历史」，点「同步到桌面」。首次操作需允许本地连接。回到 Windows 窗口，在「搜索文件」选择「Chrome 下载」。

Chrome 扩展里的「导入旧下载记录」可补录 Chrome 仍保留的历史，每批最多 100 条。旧记录的来源从「未知」开始。可以在扩展详情中核对候选或补充网页，之后再次同步。

### Motrix／aria2 接管下载

1. 保持现有的浏览器接管设置，并启动本机 Motrix 或 aria2。
2. 在 FileRecall 顶部点「Motrix／aria2」。填下载器设置中显示的 RPC 端口。FileRecall 预填 `16800`，使用你的实际端口。如果下载器设有 RPC 密钥，也在此输入。
3. 点「连接并同步」。从浏览器下载测试文件，交给 Motrix 完成，再到 FileRecall 点「立即同步」，或等下一次约 30 秒的自动同步。用「Motrix／aria2」筛选查看结果。

FileRecall 读取本机 RPC 中仍保留的最近 500 个已停止任务，导入其中已完成的文件。下载器报告唯一已使用的 HTTP(S) 直链时，详情会显示「打开下载地址」。网页来源保留为未知。重复同步会去重，断开连接会保留已导入记录。

## 4. 核对文件来历

1. 找到一个本地文件，点开详情里的「文件来历」。名称或路径吻合的下载记录会列为候选。
2. 核对原下载路径、时间和来源。确定是同一份文件时选「确认是同一文件」。也可以「排除」，之后可撤销。
3. 文件在同一磁盘卷的已授权目录间改名或移动后，搜索旧名并点「定位现址」。文件删除后可通过「已丢失」找到历史。详情中有可信网页或已记录的下载地址时，可打开原网页或直链。

## 5. 管理授权与常见问题

| 遇到的情况 | 怎么处理 |
| --- | --- |
| 想停止扫描并保留历史 | 在「授权目录」点「停止索引」。历史仍可搜，退出授权范围的文件正文会从索引移除。父目录仍在授权时，子目录也仍在扫描范围内。 |
| 想清掉某个目录的本地索引历史 | 点「停止并清除历史」，或在已停止的目录旁点「清除历史」。磁盘文件会保留。独立同步的 Chrome 和 Motrix 下载记录仍可在相应筛选下查找。 |
| 文件已经移动，结果还显示旧状态 | 等待自动监控更新，或在「授权目录」点「重新扫描」。跨卷移动、重复副本或证据不足时，历史可能继续显示丢失或候选。 |
| Chrome 同步成功，但桌面没有显示 | 回到桌面窗口后重新搜索，也可在「Chrome 设置」点「刷新下载记录」。检查扩展 ID 和本地连接权限。 |
| Motrix 没看到记录 | 确认下载器正在运行、任务已完成，并核对 RPC 端口和密钥，再点「立即同步」。已从下载器清理且从未导入的任务无法补录。 |
| AI 搜不到或提示暂无可用正文 | 确认已下载模型、已开启正文索引，并且扫描完成。可回到「字面搜索」尝试文件名或确切短语。 |
| 热键冲突 | 在「搜索热键」改用另一个组合，例如 `Ctrl+Alt+F10`。新组合保存成功后才会替换原来的热键。 |
